# qua-agents benchmark reports

Hand-assembled reports on qua-agents benchmark runs. Each report is a single
self-contained HTML page; open it in a browser. Numbers come from the per-cell
`result.json` documents and the judge's `qab show` / `qab compare-models` output;
the run identifiers at the bottom of each report map back to the qua-agents GUI
and the cell directories under `~/qab-runs/`.

| Report | Covers |
|---|---|
| [2026-09-08-effort-high-overnight.html](2026-09-08-effort-high-overnight.html) | sonnet-5, opus-5 and haiku-4.5 at high effort on arbel, qolab and gilboa, 7–8 Sep 2026, with the dag-walk control |
| [2026-09-09-frameworks-overnight.html](2026-09-09-frameworks-overnight.html) | qua-agents (opus-5, sonnet-5), the dag-walk control and tinycal (opus-5) on arbel and gilboa, two qubits each, 8–9 Sep 2026: node executions, re-executions, calibrated chips and cost, agent against the graph's defaults; qolab excluded (chip fault), all run ids listed |
| [2026-09-14-frameworks-opus-sonnet-qwen.html](2026-09-14-frameworks-opus-sonnet-qwen.html) | tinycal, qua-agents and the dag-walk control with opus-5 and sonnet-5 at high effort (14–15 Sep 2026) and qwen3.8-27b via OpenRouter (16–17 Sep) on arbel, gilboa and qolab: three-qubit rounds then one new qubit per round for Opus/Sonnet, three-qubit rounds for qwen; RB error, gate lengths, cost, hard cases, where each cell stuck, all run ids. Generated by `make_fwcmp2_report.py` from the cell documents; re-run to refresh |
| [2026-09-18-recipe-night-qwen-tinycal.html](2026-09-18-recipe-night-qwen-tinycal.html) | tinycal with qwen3.8-27b via OpenRouter on all six qolab qubits, fifteen gilboa qubits and three arbel qubits, night of 18–19 Sep 2026, after a day of recipe and qua-libs node iteration on qolab (working-copy libraries b0ba588 / fc2f37a, same snapshots and scramble as the 14–17 Sep report): completion, gate fidelity, cost and context per backend, every failure classified, the shared-state incidents, all run ids. Generated by `make_night2_report.py` from the cell documents; re-run to refresh |
